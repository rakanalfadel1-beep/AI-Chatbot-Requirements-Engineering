# 🤖 AI Chatbot for Customer Support: Requirements Engineering

## 📌 Project Overview
The purpose of the AI chatbot is to ease the process of seeking help through customer support[cite: 2]. This tool is beneficial for customers by being efficiently available 24/7[cite: 2]. It cuts costs effectively whilst ensuring customer's satisfaction[cite: 2]. The system initiates conversations between the organization's customer support and users to handle common issues and provide product information[cite: 2].

## ⚙️ Elicitation & Validation Methodology
* **Requirements Elicitation:** Requirements were gathered using interviews, questionnaires, and observation[cite: 2]. A survey was conducted targeting users of services like STC, Spotify, noon, and Amazon to identify desirable features[cite: 2]. 
* **Requirement Validation:** The requirements underwent rigorous validation, including completeness, technical feasibility, operational feasibility, and consistency checks[cite: 2].

## 🚀 Key Specifications & Deliverables
* **Functional Requirements:** The system handles multiple languages, processes transactions (such as order placement or cancellations), allows file uploads, and integrates easily with existing CRM and ticketing systems[cite: 2].
* **Non-Functional Requirements:** The chatbot response time must not exceed 3 seconds, and it must maintain a minimum uptime of 99%[cite: 2]. The system ensures data exchanged is encrypted for security and is scalable to handle growing customer usage[cite: 2].
* **System Modeling:** Developed Use Case and Activity diagrams to depict stakeholder interactions and user flows clearly[cite: 2].
